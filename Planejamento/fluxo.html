Diagrama 1 - Arquitetura em Camadas (Request Flow)

Fluxo de uma Requisicao no Sistema

Cliente
(Browser)
→
Routes
(Express Router)
→
Middleware
(Auth / Admin)
→
Controller
(req, res)
→
Service
(Logica)
→
Repository
(Dados)
→
JSON
(Persistencia)

Responsabilidade de cada camada:

RoutesDefine endpoints e metodos HTTP, direciona para o controller correto
MiddlewareIntercepta a requisicao: verifica sessao (auth), perfil (admin), trata erros
ControllerRecebe req/res, extrai dados, chama o Service e retorna resposta (view ou redirect)
ServiceContem regras de negocio: validacoes, limites, regras de emprestimo
RepositoryAcesso exclusivo aos dados: leitura/escrita dos arquivos JSON
Nota: A resposta percorre o caminho inverso: Repository retorna dados ao Service, que processa e retorna ao Controller, que renderiza a view ou redireciona o usuario.

Diagrama 3 - Fluxo de Emprestimo e Devolucao

Fluxo de Emprestimo de Livro

Usuario logado acessa /livros/:id
Exibe detalhes do livro + botao Emprestar
Usuario clica em Emprestar este livro
authMiddleware verifica sessao
Usuario autenticado?
SIM
POST /emprestimos - emprestimoController recebe livroId
emprestimoService verifica regras de negocio
Livro disponivel?
SIM
emprestimoRepository.create() - cria emprestimo
livroRepository.update() - marca disponivel = false
Redireciona para /emprestimos/meus

NAO
Exibe erro: Livro indisponivel
NAO

Fluxo de Devolucao

Usuario acessa /emprestimos/meus
Exibe lista de emprestimos ativos
Usuario clica em Devolver
POST /emprestimos/:id/devolver
emprestimoService.devolver() - atualiza status e data
livroRepository.update() - marca disponivel = true
Devolucao registrada, livro disponivel novamente

Diagrama 5 - CRUD de Livros (Administrador)

Fluxo de Gestao do Acervo

Cadastrar Livro

Admin acessa /admin/livros/novo
authMiddleware + adminMiddleware
Exibe formulario vazio
Admin preenche dados e submete
POST /admin/livros - livroController.create()
livroService valida dados
livroRepository.create() - salva em livros.json
Redireciona para /admin/livros com sucesso

Editar Livro

Admin acessa /admin/livros/:id/editar
Exibe formulario preenchido com dados atuais
Admin modifica campos e submete
POST /admin/livros/:id - livroController.update()
livroRepository.update() - atualiza em livros.json
Redireciona para /admin/livros com sucesso

Remover Livro

Admin clica Remover em /admin/livros
POST /admin/livros/:id/deletar
Livro tem emprestimo ativo?
NAO
livroRepository.delete() - remove do JSON
Livro removido com sucesso
SIM
Erro: nao pode remover livro emprestado
